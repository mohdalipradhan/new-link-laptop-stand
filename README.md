# New Link laptop stand: HTML + asset pack

Open index.html in a browser. No installation, build step, CDN or network access is needed to render the page. External WhatsApp and store links require internet access.

- index.html: responsive product page covering the 13 content sections in the PDF; repeated PDF navigation and footers consolidated.
- styles.css: reference-inspired styling and mobile layouts.
- script.js: eight-image gallery, keyboard navigation, mobile menu, payment preference dialog.
- assets.html: browse and download the reference images and generated assets.
- assets/manifest.json: file dimensions and source PDF page numbers.

The PDF contains 16 desktop pages (13 content + 3 asset inventories) and 13 mobile versions. It contains embedded image frames, not the original GIF/MP4 files listed in the asset inventories. The pack preserves those stills; it does not claim to recover animation or original source quality. AI-labelled and supplier-labelled images are carried over from the PDF, not newly generated.

Checkout is not connected to a payment gateway. Buy buttons open a payment preference dialog and then let the visitor contact the seller on WhatsApp. No messages are sent automatically. The two PDF prices, ₹599 online and ₹699 COD, are retained. Confirm current prices before public launch.

Before publishing, supply confirmed compatibility, maximum load, delivery timing, returns, warranty and legal policy details. Unknown email and social URLs were omitted. No policy text or product claims were invented. The reference's cream/charcoal/gold palette is deliberately preserved. The page is local and has not been deployed.

Validation: JavaScript syntax, local links, anchor targets, unique IDs, asset manifest, and all 32 JPEG files checked successfully. Visual layout and interactive browser QA remain unverified because local browser launch and file previews were unavailable in this environment.

The Height & angle section uses a manual two-slide carousel with generated 6 cm / 14 cm illustrations, arrow buttons, setting selectors, keyboard controls and mobile swipe support.

Everyday problems panel: six locally stored gold outline SVG icons, adapted from Tabler Icons 3.49.0 under MIT. Attribution and license in assets/icons/.

The setup comparison section is native HTML/CSS with two separate WebP product scenes and a Tabler keyboard SVG. All headings, labels, captions, note and height-settings link remain editable and accessible HTML. No full UI screenshot is embedded.
